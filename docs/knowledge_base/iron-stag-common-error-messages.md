# Iron Stag - Common Error Messages

## Overview
A list of the most common errors and issues in Iron Stag, with fixes you can try right away.

## Key Information
- Most issues are caused by connectivity, permissions, or unsupported images.
- If a subscription doesn’t appear, you can restore purchases from Profile.

## Step-by-Step
1. Identify the error message or symptom below.
2. Follow the recommended fix.
3. If the issue persists, contact support.

## Common Questions
**Q: "Analysis Failed"**
A: Check your internet connection, try a smaller image, and try again later.

**Q: "Image too large"**
A: Photos over ~10MB may fail. Try a smaller image or lower resolution.

**Q: "Not a Deer"**
A: Only Whitetail or Mule Deer photos are supported.

**Q: Login Failed**
A: Verify your email/username and password, or use "Forgot Password" to reset.

**Q: Subscription Not Showing**
A: Tap "Restore Purchases" in Profile, confirm you’re on the same Apple ID/Google account, and try again.

**Q: Camera Not Working**
A: Verify camera permissions, restart the app, and restart your device.

**Q: Images Not Loading in History**
A: Local images may have been cleared; scan data remains but images won’t display. If cloud images are enabled, reopen the scan to load the cloud thumbnail.

**Q: "Queued for Upload" / Offline Banner**
A: You’re offline. The scan is saved locally and will upload automatically once you’re back online.

**Q: "Update Required"**
A: Your app version is below the minimum supported version. Update via the App Store or Play Store.

**Q: Tag Limit Reached**
A: Each scan can have up to 10 tags (max 30 characters each).

**Q: Error Code 401**
A: Not authenticated; sign in again.

**Q: Error Code 403**
A: Scan limit reached; upgrade to Master Stag.

**Q: Error Code 400**
A: Invalid request; check image format.

**Q: Error Code 500**
A: Server error; try again later.
